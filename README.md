# Product PPT Lite｜用 PPT 包装你的产品 · 免费分享版

给AI产品文案、产品图和风格参考，先把产品讲清楚，再做有视觉重点的排版。

**免费使用 · 允许商业PPT制作 · 禁止转售技能包**

一个独立的中文产品介绍排版 Skill，适合实体产品、产品手册、SaaS、APP和ToB方案。它提供可执行的制作流程，不是单张固定模板，也不是自带生图和PPT导出能力的软件。

## 能帮你做什么

- 实际读取材料，保留规格、数字、版本与使用条件。
- 按使用场景、产品能力与实际价值组织讲述顺序。
- 输出逐页规划、准确页面文案、原文覆盖表和待核事项。
- 输出每页完整的中文视觉提示词。
- 先做主视觉页与信息密集页，再分批延续全稿。
- 有工具时生成视觉页；支持PPT制作时，可进一步交付并检查可编辑PPTX。

默认采用米白、石墨与灰绿的极简产品画册风。你提供品牌规范或参考图时，优先采用你的视觉方向，提取构图、字图关系、字体层级与页间节奏。

## 安装

可直接下载 [技能安装包](downloads/product-ppt-lite.zip)，解压得到 `product-ppt-lite` 文件夹。

也可以下载整个仓库：

1. 点击页面上方绿色 **Code（代码）**，再选 **Download ZIP（下载ZIP）**。
2. 解压后找到 `skills/product-ppt-lite`，保留这个文件夹的全部内容与相对目录。
3. 按你使用的Agent Skills客户端说明，将文件夹放入它识别的技能目录，或通过其技能导入功能安装。
4. 重新加载技能，在支持显式调用的环境输入 `$product-ppt-lite`。

不同客户端的导入入口、目录和调用语法不同。安装这个Skill不会自动获得图片生成、图片编辑或PPTX导出工具。

## 工作流程

产品资料 → 内容核对与逐页规划 → 视觉方向 → 逐页提示词 → 代表页 → 分批制作与检查。

有认可的方向会直接延续，不要求反复确认。用户只要规划或提示词时，不会擅自继续生成文件。

## 你需要准备什么

| 输入 | 作用 |
|---|---|
| 产品描述、规格、功能和限制 | 决定哪些事实可以上版 |
| 产品实拍或真实界面 | 保持外观与功能说明准确 |
| 受众、介绍目的和页数 | 决定讲述顺序与信息密度 |
| 品牌规范或风格参考（可选） | 确定视觉语言 |

## 能力边界

- 没有真实数据，就不编效果、销量、认证、价格或用户证言。
- 参考图用于提取设计规则，不自动授权其中的照片、字体、品牌或文案。
- AI场景与概念图需注明示意属性，不能用作实物品相或功能证明。
- 图片视觉稿不等于对象级可编辑PPTX，照片内部也不会自动变成可编辑对象。
- Lite聚焦产品介绍，不包含所有营销研究与PPT专项场景，不依赖作者其他私有技能。
- 生图服务、字体、素材和PPT引擎不随本仓库打包，费用与使用规则由对应服务决定。
