# 来源与使用范围

参考来源：[《【产品介绍类】用PPT包装你的产品》](https://chenmu-tech.feishu.cn/wiki/QTI8wSWC8i0nvCkuNd3cMn3unBF)。已读取正文中的规划提示词、逐页视觉提示词、视觉生成与修改说明，并查看产品视觉示例。

这份技能采用重新编写的流程说明，不是教程原文、原作者代码或授权衍生品牌。被问及来源时如实说明，不将教程作者的方法和示例称为自己的原创案例。

| 来源方法 | 本技能的处理 |
|---|---|
| 规划报告 → 逐页提示词 → 视觉生成 | 保留三阶段与阶段交付边界 |
| 以用户场景串联问题、方案、能力和价值 | 用证据约束每个结论，按页数合并任务 |
| 统一视觉且逐页匹配内容 | 提供单一默认风格、逐页完整中文提示词和不同构图 |
| 材料不足可作合理假设 | 只允许明确标注的设计/受众假设；不补产品事实和效果数据 |
| 逐页生成、按需带入产品配图、修改后再生成 | 增加代表页、产品外观核验与文字复核 |
| 通过外链教程转PPTX | 外链工具未打包；仅在环境支持时制作并验证编辑范围 |
